# Accreditation images

Place one image per accreditation in this folder. The page will display them in the Facility Accreditations section.

**Expected filenames** (PNG or SVG recommended):

| Accreditation | Filename(s) |
|----------------|-------------|
| cGMP/Non GMP   | `cgmp.png` or `cgmp.svg` |
| USFDA          | `usfda.png` or `usfda.svg` |
| State FDA      | `state-fda.png` or `state-fda.svg` |
| EDQM           | `edqm.png` or `edqm.svg` |
| ISO:9001       | `iso9001.png` or `iso9001.svg` |
| WHO GMP        | `who-gmp.png` or `who-gmp.svg` |

Use official or licensed logos where required. If a file is missing, the section will show the accreditation name with a check icon.
